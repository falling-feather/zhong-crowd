已参与2026数媒竞赛。

## 当前内容

## 本地运行

使用Node.js 24.20.0或更新版本。带有pnpm锁文件的项目使用pnpm；运行命令在仓库根目录执行。已有依赖可直接复用。

```sh
pnpm install --frozen-lockfile
pnpm build
node scripts/serve-release.mjs
```

服务地址以终端实际输出为准。三维或WebGPU页面建议使用开启硬件加速的桌面Edge或Chrome。

## 源码组织

`src/`：核心实现；`public/`：运行资产；`scripts/`或`tools/`：构建与本地服务；`tests/`：已有回归检查。

仓库保留核心实现、依赖清单、必要运行资产、已有检查和第三方许可。报名人员表、盖章件、参赛汇报、影片、成果压缩包、开发缓存与机器环境均不纳入公开源码。
